# Parent Brand Reference — Thandava Films

## Purpose

This file records the parent-brand context that the Thandava Podcast Studio knowledge base may inherit from. It is intentionally separate from studio-specific facts.

## Parent-Child Architecture

```text
Thandava Films
└── Thandava Podcast Studio
    └── Thandava Podcast
```

### Thandava Films

The broader film/content production brand and parent creative ecosystem.

### Thandava Podcast Studio

A podcast / conversation-video production business unit within Thandava Films.

### Thandava Podcast

A podcast/show/content property that may be produced through the studio. Treat the show/property separately from the studio as the project develops.

## Parent Brand Characteristics

Working characteristics established in project context:
- Premium
- Cinematic
- Authentic
- Story-driven
- Visually strong
- Professionally produced

## Parent Brand Palette

- Obsidian Black: `#0E0D30`
- Baltic Blue: `#3D5C94`
- Pure White: `#FFFFFF`

## Inheritance Rules

The podcast knowledge base may inherit parent-brand principles, but should not automatically inherit:

- Service claims
- Technical specifications
- Pricing
- Team structure
- Production capabilities
- Client claims
- Website information
- Credentials
- Marketing promises

Those must be verified for the podcast/studio context.

## Why This File Exists

Without a parent-brand reference, the podcast repository can gradually become detached from Thandava Films or accidentally create conflicting brand claims.

This file acts as the bridge between the parent brand and the podcast studio while preserving separation between shared brand principles and studio-specific facts.
